# popup

## BalanceSection 标签页
- 标签页由 `getBalanceTabs()` 按数据动态生成：基础标签为今日消耗、总余额；启用站点营收时加入营收统计；存在 `subscription` 时加入订阅信息。
- `selectedIndex` 由动态标签列表与 `activeTab` 共同决定，偏好值不再假定固定下标；当前数据不支持所选标签时回退到总余额。
- 当存在订阅账号时，「今日消耗」面板按“订阅套餐/按量付费”拆分展示。
- 「营收统计」面板支持时间范围：今天 / 近7天 / 当月 / 自定义（`useRevenueRange`，按浏览器本地时区、含首尾日期；自定义最长 366 天，结束日期超过今天按今天计）。
  - 今天沿用缓存快照；其它范围实时调用适配器（营收 `getSiteRevenue`，个人消耗 `getRangeUsageStats`），随全局刷新重新查询。
  - 营收面板主金额为「预计净收益」= 总流水 − 总消耗；总流水只汇总开启营收统计的站点（按 origin 去重），总消耗为未开启营收的个人账号同范围消耗，明细按总流水、总消耗顺序展示。预计净收益未扣除手续费、退款等其他成本；营收全部失败显示待计算。
  - 本地每日记账（`services/dailyLedger.ts`，存储键 `daily_usage_ledger`）：每次刷新成功后，个人账号按账号 id 记当天消耗(USD)，营收站点按 origin 记当天营收(USD)，同一天取最大值，保留 400 天，删除账号时清除其记录。站点会清理历史日志导致区间值偏小，因此区间结果 = max(站点区间值, 本地记录之和)；使用了本地记录的金额带 `*` 标注，并说明记录起始日期。站点不支持区间查询时，有本地记录则仅用本地记录，否则报错。记录只能从启用后开始，更早已被清理的数据无法补回。
  - 不支持区间消耗的个人账号（目前为 Cubence）计入「消耗未获取」，不当作零消耗。
